# PRD: Join Bubble Flow

Status: Defined in project-brief.md — full PRD to be written.

## Summary
1. Free browsing without login
2. Click View on card → opens Group Page
3. Click Join Bubble inside Group Page → Google Sign-In if not logged in
4. AI checks: day/time availability, hours/week commitment, experience level
5. Outcomes: join / suggest alternative bubble / waitlist
6. Notification consent required before entering
7. Enter GroupPage as Member

## Matching Logic
- Required: same topic + overlapping day/time
- Preferred: similar goal
- Bubble statuses: open / full / active / closed
- Min members to activate: 4 | Max: configurable by Founder (up to 8)
